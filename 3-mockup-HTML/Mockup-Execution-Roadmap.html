  • Provider fee (R20) — returns 0 during free period
  • Pure TS in src/lib/settlement.ts — test-first approach
Step 2
Result Entry RPC + Audit Log
Infra 1 session cum: 3–4 Critical
  • audit_log table (append-only, R29)
  • Atomic submit_match_result + correct_match_result RPCs
  • Replace non-transactional submitResult()
Step 3a
Bet Pipeline — Schema + Basic Routing
Infra 1–2 sessions cum: 4–6 Critical
  • bet_requests + sporadic_pools tables (full schema)
  • Attribution columns (R26) on bets + bet_requests
  • Routing: mandatory_self → direct; others → bet_requests → basic capacity check → bets
Concurrency hardening (row locks, LIFO, race protection) deferred to Step 3b post-launch. Schema is identical — only transaction isolation changes. Single-bookkeeper workflow has no concurrency risk.
Step 4
Bookkeeper Bet Entry + Match Enhancements + Inbox Zero
Bookkeeper 2–3 sessions cum: 6–9 Critical ◆ Checkpoint
  • Bet entry at /bets, mandatory self-bet auto-gen, 小盤 option

  • Betting close (封盤), player change flow, bulk reduction
  • Inbox zero pattern on matches page
◆ Checkpoint: Bookkeeper core is functional. Reassess velocity and re-estimate remaining steps.
Step 5
Per-Match Report Redesign
Bookkeeper 1–2 sessions cum: 7–11 Critical
Rewrite MatchBetReport.tsx with correct 1:1 payout model. Per-person breakdown, multi-match day routing, sporadic pool report.

Weekly Report (每週報表)
Bookkeeper 1–2 sessions cum: 8–13
/reports page — per-member weekly summary. Screenshot-friendly for Line group.
Step 7
Monthly Settlement (月度結算)
Bookkeeper 2 sessions cum: 10–15 Critical
/settlement page — auto-calculated, double-check audit, settlement lifecycle, inactive debt → referrer.
Step 9
Auth + Member Read-Only View
Shared 2–3 sessions cum: 12–18 Critical ⚠ Security Gate
  • Bookkeeper: Supabase Auth + middleware + RLS
  • Members: member_tokens table + personal links + token validation
  • Member read-only view at /m/[token]/: today's matches, my bets, my balance
  • No write operations — bookkeeper enters all bets. Mobile-first layout.
⚠ No real data before this. Steps 1–7 run with permissive RLS. No real financial data until auth is complete.
