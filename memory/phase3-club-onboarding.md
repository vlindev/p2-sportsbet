# Scaling Framework — Questions for Future Clubs
(Removed from organizer brief — for internal use when onboarding new clubs)

**Club Structure:** name, member count, play day frequency, mandatory participation rules, course booking process

**Match Format:** format type, players per team, holes per match, win condition, per-hole scoring, difficulty index

**Handicap:** used?, type (points/swings/other), how value decided, how applied across holes

**Betting:** bet types, peer-to-peer or house, rake %, base unit, mandatory bets, capacity system, multiple matches, oversubscription handling

**Settlement:** frequency, fixed date, report cadence, payment method
